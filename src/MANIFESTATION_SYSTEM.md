# 🌟 显化系统架构文档

## 系统概述

MANIFITION ROOM 的核心显化系统实现了从**虚拟图像→AI分析→感官锚点→现实行动**的完整流程。

## 🔄 完整流程

### 1. 图片上传（愿景环廊阶段）
- **位置**：左侧面板 → "上传愿景图片"
- **功能**：拖拽或点击上传个人愿景图片
- **组件**：`/components/ui/ImageUploader.tsx`

### 2. AI色彩分析
**分析引擎**：`/lib/imageAnalyzer.ts`

提取维度：
- **主色调**（Dominant Colors）：通过Canvas API采样像素
- **情感基调**：
  - `energy`（0-100）：饱和度+明度综合
  - `warmth`（-100~100）：冷暖色倾向
  - `depth`（0-100）：明暗对比度

### 3. 人生维度映射
**映射逻辑**：`mapColorToDimensions()`

色相→人生维度：
- **红色系**（0-30°, 330-360°）→ 事业成就、人际关系
- **黄橙色系**（30-90°）→ 创造表达、财富丰盛
- **绿色系**（90-150°）→ 身心健康、精神成长
- **蓝色系**（150-270°）→ 精神成长、身心健康
- **紫色系**（270-330°）→ 精神成长、创造表达

能量补充规则：
- 高能量（>70）→ 增加"事业成就"
- 高温暖（>50）→ 增加"人际关系"
- 低对比（<30）→ 增加"身心健康"

### 5. 五官感知锚点系统

**核心理念**：将抽象目标具象化为可感知的多感官体验

| 感官维度 | 作用 | 示例 | 颜色编码 |
|---------|------|------|----------|
| 👁️ 视觉 | 创建视觉记忆点 | "金色光芒" | #FF6B9D |
| 👂 听觉 | 音频情境联想 | "鼓掌声" | #6BCF7F |
| ✋ 触觉/动觉 | 身体感受锚定 | "坚实的步伐" | #FFD93D |
| 👃 嗅觉 | 气味记忆触发 | "咖啡香" | #C9A0DC |
| ❤️ 情绪 | 核心感受状态 | "自豪感" | #6EC6FF |

**科学依据**：
- NLP（神经语言程序学）的感官次系统理论
- 具身认知理论（Embodied Cognition）
- 情景记忆增强原理

### 6. 3D可视化（显化核心阶段）

**主组件**：
- `ManifestationSpace.tsx`：整体空间布局
- `ManifestationModule.tsx`：单个模块的3D表现

**视觉特性**：
- 圆形分布：模块围绕中心呈圆形排列
- 动态效果：
  - 悬浮动画（sin波浮动）
  - 自转效果
  - Hover放大（1.08倍）
  - Selected放大+高亮（1.15倍 + 强发光）
- 五感锚点可视化：选中时显示5个彩色小球

### 7. 详情面板

**组件**：`/components/ui/ModuleDetailPanel.tsx`

**内容结构**：
1. 维度标识（图标+名称+描述）
2. 愿景陈述
3. 确认语/显化语句
4. **五感锚点系统**（带图标+颜色编码）
5. 目标路线图（3个月/6个月/1年）
6. 行动清单（每日/每周/每月）

## 🎨 交互流程

```
用户上传图片
    ↓
Canvas提取像素 → 色彩聚类分析
    ↓
计算情感参数（energy/warmth/depth）
    ↓
映射人生维度（3-4个）
    ↓
生成显化模块（含五感锚点）
    ↓
存储到Zustand state
    ↓
3D空间可视化
    ↓
用户点击模块 → 显示详情面板
    ↓
查看五感锚点 + 行动计划
```

## 🚀 使用指南

### 第一步：上传图片
1. 导航到"愿景环廊"阶段（Stage B）
2. 在左侧面板找到"上传愿景图片"
3. 拖拽或点击上传能代表你人生愿景的图片

### 第二步：查看分析结果
- 上传后会自动显示Toast通知
- 左侧面板显示"已生成显化模块"卡片
- 列出生成的维度（如：🎯 事业成就、💝 人际关系）

### 第三步：进入显化核心
- 点击"进入显化核心查看详情 →"按钮
- 或手动切换到Stage D

### 第四步：探索模块
- 3D空间中显示彩色球体
- Hover查看预览
- 点击查看完整详情面板

### 第五步：深度规划
- 阅读五感锚点（建立多维度记忆）
- 查看目标时间线
- 记录每日/每周/每月行动

## 🔮 从虚拟到现实的桥接

### 理论基础
1. **视觉化原理**：大脑无法区分真实经历和生动想象
2. **感官具象化**：多感官记忆比单一视觉记忆强8倍
3. **实施意图**：具体的"何时+何地+如何"计划提升执行率91%

### 实践路径
```
虚拟层（图片）
    ↓ AI解析
概念层（人生维度）
    ↓ 模板生成
感知层（五官锚点）
    ↓ 身体记忆
行动层（每日行动）
    ↓ 持续实践
现实层（目标显化）
```

## 🛠️ 技术栈

- **3D渲染**：React Three Fiber + Three.js
- **状态管理**：Zustand
- **图像处理**：Canvas API
- **色彩分析**：自定义K-means聚类算法
- **UI组件**：Tailwind CSS + Lucide Icons
- **通知系统**：Sonner Toast
